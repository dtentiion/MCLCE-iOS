# Roadmap

Not set in stone - items will change as we progress.

## Completed

- App shell, CMake support for the iOS toolchain, CI and basic controller support
- A working copy of the stock SWF menus and HUD using Ruffle
- All of the relevant menus (main menu, Help & Options, world selection, creation/load and save options)
- All of the content of the TU19 game - survival, creative, the tutorial, the Nether and the End
- A Metal based world renderer, complete with HUD and other menus
- appropriate music, sfx and ambient sounds
- save/autosave functionality
- support for texture and skin packs from user supplied files

## Upcoming

- Address the issues listed in [STATUS.md](STATUS.md)
- Verify all aspects of gameplay with the TU19 source and the Windows64 version
- implement controller 'rumble'

## Future

- Multiplayer - both direct connect and LAN, which should be able to connect to the Windows64 version
- split screen with multiple controllers
- keyboard/mouse support on the iPad

## Out of scope

- App Store release, for obvious reasons

## Possibly

- an equivalent Android version using the same code base
- a mod loader
- touch based on screen controls
